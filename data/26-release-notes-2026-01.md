# Release Notes – January 2026

_Release window: 2026-01-15_

This release focused on improving throughput, collaboration, and reporting quality for Growth and Enterprise customers.

## Highlights

### Growth API rate limit increased
The default **Growth** API limit has been increased from **120 requests per minute** to **180 requests per minute**.

See the API rate-limit documentation for the current authoritative values by plan.

### Slack approval actions now available on Growth
Interactive approval actions in Slack are now available on **Growth** as well as Enterprise.

Starter remains limited to notification-only Slack behavior.

### Scheduled report export improvements
Scheduled report exports have been improved for workspaces with larger dashboards and more frequent delivery schedules.

These improvements do not change the fact that scheduled exports remain a Growth and Enterprise feature.

### Billing Admin role clarification
Role labels and descriptions have been clarified in the admin UI to better distinguish billing-only permissions from general workspace administration.

## Notes

As with any release, older help material or onboarding notes may still reflect previous defaults for a short period. When in doubt, use the latest product documentation and plan/policy pages rather than historical release notes alone.
