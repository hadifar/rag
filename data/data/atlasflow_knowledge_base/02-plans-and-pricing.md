# AtlasFlow Plans and Pricing

This document summarizes the commercial plan structure for AtlasFlow.

AtlasFlow is offered on three paid plans:

- Starter
- Growth
- Enterprise

The exact commercial terms of a subscription depend on billing frequency and contract type, but the feature differences below are the main product-level distinctions customers should use when comparing plans.

## Plan overview

### Starter
Starter is intended for smaller teams beginning to formalize recurring operational work.

Typical characteristics:

- basic workflow creation and execution
- standard dashboards
- manual report exports
- personal API access
- email and portal support during business hours
- 30-day audit event history

Starter does **not** include:

- SSO
- scheduled report exports
- workspace API keys
- webhooks
- interactive Slack approval actions

Starter is available with a minimum of 5 seats.

### Growth
Growth is intended for teams that need stronger automation, better controls, and broader platform capabilities.

Growth includes everything in Starter, plus:

- advanced workflow automations
- SSO
- scheduled report exports
- workspace API keys
- webhooks
- interactive Slack approval actions
- 180-day audit event history

Growth is available with a minimum of 10 seats.

### Enterprise
Enterprise is intended for organizations that need the broadest feature set, stronger support commitments, and contractual flexibility.

Enterprise includes everything in Growth, plus:

- enterprise support options
- extended platform controls
- regional data residency guarantees by contract
- custom retention options
- higher default API limits
- commercial and security terms negotiated by contract

Enterprise plans are sold on a contract basis.

## Feature summary by topic

### Authentication
- Starter: local login only
- Growth: local login and SAML SSO
- Enterprise: local login and SAML SSO

### API access
- Starter: personal API keys
- Growth: personal API keys and workspace API keys
- Enterprise: personal API keys and workspace API keys

### Reporting
- Starter: manual exports only
- Growth: manual exports and scheduled exports
- Enterprise: manual exports and scheduled exports

### Audit visibility
- Starter: 30-day audit event history
- Growth: 180-day audit event history
- Enterprise: extended audit visibility and custom retention options by contract

### Support
- Starter: standard support
- Growth: enhanced standard support
- Enterprise: priority support options and contract-based service levels

## Notes

This document is intended as a plan comparison summary. For precise operational behavior, especially around data retention, support commitments, and hosting guarantees, use the more detailed policy documents rather than relying on this page alone.
